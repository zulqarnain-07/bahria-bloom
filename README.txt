Bahria Bloom - blossom redesign for cms.bahria.edu.pk

Install (Chrome, Edge, Brave; Chrome 111 or newer)
1. Unzip this folder.
2. Open chrome://extensions and switch on Developer mode.
3. Click "Load unpacked" and choose the unzipped bahria-bloom folder.
4. Open https://cms.bahria.edu.pk/ and reload.

Files
theme.css       all colours, type and layout (palette tokens are at the top)
blossom.js      petal shower, click bursts, the small petal on/off button
content.js      builds the door illustration, portal icons and dashboard greeting
chart-theme.js  recolours the attendance chart
manifest.json   applies everything to https://cms.bahria.edu.pk/*

Petals respect "reduce motion" in your OS, and the round button in the
bottom-right corner turns them off (remembered between visits).
