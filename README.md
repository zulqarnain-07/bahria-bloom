## 📦 Installation

**Supported browsers:** Chrome, Edge, and Brave  
**Requirement:** Chrome 111 or newer

1. **Download** the extension using the button above.
2. **Extract** the downloaded ZIP file.
3. Open `chrome://extensions` in your browser.
4. Enable **Developer mode**.
5. Click **Load unpacked** and select the extracted `bahria-bloom` folder.
6. Visit [cms.bahria.edu.pk](https://cms.bahria.edu.pk/) and reload the page.
